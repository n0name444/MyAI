# MyAI v1.4.3 — локальный ассистент (Machenike S15 Pulsar S / RTX 4050 6 GB)

Локальный русскоязычный ИИ-помощник: чат на Qwen3-4B (4-bit), интернет-поиск, погода, аниме, калькулятор,
долговременная память и **безопасное** управление Windows.

## Запуск (Windows)

1. Установите Python 3.12 или 3.13 с галочкой *Add to PATH*.
2. Запустите `start.bat`. Первый старт долгий: ставится PyTorch с CUDA (~2–3 ГБ), зависимости и скачивается модель (~8 ГБ).
3. Откроется `http://127.0.0.1:5000`. Модель грузится в фоне — статус виден слева.

Если `start.bat` не нашёл видеокарту, он предупредит и спросит, продолжать ли на CPU (медленно, меньшая модель).
Индекс колёс PyTorch задан в начале `start.bat` (`TORCH_INDEX`); актуальный адрес — на pytorch.org/get-started.

Диагностика: `.venv\Scripts\python diagnostics.py`. Логи: `myai.log`.

## Что умеет

| Запрос | Что происходит |
|---|---|
| обычный вопрос | ответ модели, потоком |
| «Какая погода в Архангельске / завтра в Москве» | Open-Meteo (город в любом падеже) |
| «Новости про Python», «Курс доллара», «Найди в интернете …» | поиск + чтение страниц + ответ по источникам |
| «Найди аниме про машины», «фэнтези с магией 2020–2026 без комедии», «похоже на Solo Leveling» | разбор критериев → поиск в AniList с фильтрами → проверка → подборка с пояснениями (см. ниже) |
| после подборки: «покажи ещё», «без комедии», «посильнее», «поновее» | уточнение предыдущей подборки |
| «Посчитай 125 × 48», `2^10`, «12 умножить на 3» | безопасный калькулятор |
| «Запомни: …», «Что ты помнишь», «Забудь про …», «Забудь всё» | долговременные заметки |
| «Открой Блокнот / Chrome / Discord / Steam…», «Закрой …», «Открой ютуб», «Перейди на example.com» | управление ПК (белый список) |
| «Напиши в окне привет», «Нажми энтер / Ctrl+C» | ввод в **предыдущее** окно |

Кнопка «Стоп» (или Esc) прерывает генерацию. «Новый чат» сбрасывает контекст (память остаётся), а «Стереть историю и память…» в меню «⋯» стирает историю чата, имя и память (журнал вычислений и калькуляторы не затрагиваются). Под каждым ответом есть «Копировать» и «Повторить вопрос», у блоков кода своя кнопка копирования. Пока идёт ответ, в поле ввода можно набирать следующее сообщение.

## Поиск аниме (v1.4)

Запрос проходит несколько шагов:

1. **Разбор критериев** (`tools/anime_query.py`): жанры, теги, годы («2020–2026», «после 2015», «90-х», «новинки»), формат (сериал/фильм),
   исключения («без комедии»), количество («топ 5»), «похоже на …» / «понравилось …», черты героя. Сначала правилами (мгновенно, без GPU);
   если правила мало что поняли и модель уже загружена — ещё и через Qwen (ответ модели проверяется по белому списку жанров и тегов).
2. **Поиск** (`tools/anime.py`): AniList с фильтрами по жанрам, тегам, годам, формату. Если фильтры недоступны или ничего не нашли —
   прежняя цепочка по названию Jikan → AniList → Kitsu.
3. **Проверка и ранжирование:** год, формат, статус (ещё не вышедшее отбрасывается), порог популярности, жанры и теги, дубли сезонов.
   Если строгих совпадений мало, добираются частичные — с пометкой в примечании.
4. **Ответ:** карточки формирует код (название, год, оценка — из каталога), а Qwen только пишет строку «почему подходит».
   Если модель не загружена или ответила не по формату — показываются причины совпадения, найденные кодом.
5. **Уточнения:** после подборки «ещё» исключает показанное, «без комедии» / «посильнее» / «поновее» меняют критерии. «Новый чат» сбрасывает.

Количество и скорость:
* За один раз показывается до 20 тайтлов («Найди 20 аниме…», «топ 50» → 20). Если названо число, а нашлось меньше или упёрлись в потолок,
  в конце ответа есть примечание («Нашлось 11 из 20 запрошенных…»). Пояснения «почему подходит» пишет модель только для первых 8 тайтлов,
  у остальных — причины совпадения из кода; в длинном списке нет описаний.
* Ответы AniList и Jikan кэшируются в памяти на 3 часа (до 256 записей), поэтому уточнения («ещё», «без комедии») и повторные запросы
  быстрее и не расходуют лимиты каталогов. Неудачные ответы не кэшируются. Время жизни: переменная `MYAI_ANIME_CACHE_TTL` в секундах
  (`0` — выключить). Кэш очищается при перезапуске. Запросы к Jikan выдерживают паузу 0,4 с (их лимит — 3 в секунду).

Ограничения: черты сюжета («слабый, но растёт») определяются по английским описаниям и только приблизительно; русские названия
конкретных тайтлов находятся лучше, если модель загружена (она переводит название).

## Диагностика маршрутов (v1.4.1)

Каждое сообщение записывается в `logs/routes.jsonl`: куда оно ушло и почему, сколько заняло, чем закончилось
(`ok` / отказ инструмента / ошибка / остановлено кнопкой «Стоп»). Сводка:

    .venv\Scripts\python route_report.py            # весь журнал
    .venv\Scripts\python route_report.py --last 200

Она показывает по каждому маршруту число запросов, долю отказов и ошибок, среднее и p95 время, последние неудачные фразы
и самые частые причины выбора маршрута. Файл остаётся на этом компьютере; текст фразы обрезается до 120 символов,
длинные числа и e-mail маскируются. Отключить: переменная окружения `MYAI_ROUTE_LOG=0`.
Отказ определяется по тексту ответа инструмента (эвристика), поэтому это ориентир, а не точный учёт.

Проверка роутера: эталонные фразы лежат в `tests/route_cases.py`. Нашёл фразу, которую MyAI понял неправильно, — допиши её туда
с нужным маршрутом, и тест `tests/test_router.py` покажет, что починить.

**Защита от команд в найденном тексте.** Страницы из интернета и описания тайтлов передаются модели как недоверенные данные:
из них вырезаются служебные токены чата и фразы вроде «игнорируй предыдущие инструкции» (в журнал `myai.log` пишется предупреждение),
а системный промпт запрещает выполнять команды из источников. Это снижает риск, но не гарантирует его отсутствия:
веб-маршрут при этом не имеет доступа к управлению ПК.

## Безопасность управления ПК

* Разрешены только приложения из белого списка (`tools/computer_control.py`, `APPS`). `cmd`, PowerShell и произвольные команды **не поддерживаются**.
* Ввод текста и клавиш **запрещён** в терминалы (cmd, PowerShell, Windows Terminal, regedit…) и в окно самого MyAI.
* Закрытие — мягкое (приложение может спросить о сохранении). Принудительно: «закрой принудительно блокнот». Проводник не закрывается.
* Разрешены только адреса `http`/`https`. Допустимые клавиши — enter, esc, tab, space, стрелки, Ctrl+A/C/V/X/Z/Y/S/F.
* Сервер слушает только `127.0.0.1`, проверяет заголовки `Host`/`Origin` (защита от DNS-rebinding) и требует токен сессии.
* Ввод текста: «напиши в окне …» работает так: MyAI переключается на предыдущее окно (Alt+Tab) и печатает туда. Сначала откройте нужное приложение.

## История вычислений (этап 4)

История вычислений хранится отдельно от переписки и долговременной памяти в файле
`calculator_history.sqlite3` рядом с приложением. Она переживает команду «Новый чат».

Команды в чате:
- `покажи историю вычислений` — последние 20 расчётов с номерами;
- `последний результат` — последний сохранённый числовой результат;
- `повтори последний расчёт` — повторить последний расчёт;
- `повтори расчёт 12` — повторить запись с номером 12;
- `на основе последнего результата плюс 7` — подставить предыдущий результат в новое выражение.

Журнал хранит до 500 последних успешных вычислений. Ошибочные расчёты не сохраняются.


## История вычислений в интерфейсе (этап 5)

В боковой панели (на узких экранах это выезжающее меню ☰) есть пункт «Вычисления». Панель состоит из трёх вкладок: «Журнал» (последние 100 расчётов с кнопкой «Повторить»), «Калькуляторы» (формулы, шаблоны и ваши мини-калькуляторы) и «Обмен» (локальный каталог, импорт и экспорт). Очистка журнала требует подтверждения и не затрагивает историю чата или долговременную память. Команды этапа 4 в чате продолжают работать.


### Stage 6 — поиск и экспорт истории вычислений

В панели «Вычисления» доступны поиск по выражению, фильтр по диапазону дат (UTC) и экспорт отфильтрованных записей в CSV для Excel. Экспорт включает до 500 последних записей, соответствующих фильтрам. Значения CSV, начинающиеся с символов формул электронных таблиц, экранируются для снижения риска CSV-инъекций.


### Аналитика вычислений (Stage 7)
В панели «Вычисления» отображаются число записей журнала, активные дни, наиболее частый тип операции, ежедневная активность и разбивка по типам операций. Период графика можно менять (7/14/30/90 дней). Все даты аналитики используют UTC; статистика рассчитывается по сохранённому журналу (до 500 последних вычислений по умолчанию).


### Пользовательские формулы и шаблоны (Stage 8)
На вкладке «Калькуляторы» есть блок «Быстрая формула». Введите выражение, например `price * quantity`, и для каждой переменной появится числовое поле, JSON писать не нужно. Формулу можно вычислить, сохранить под именем, загрузить позднее или удалить. Встроены шаблоны цены со скидкой, НДС, стоимости покупки, прибыли и среднего значения. Имена переменных: латинские буквы и цифры, до 20 знаков. Формулы используют только арифметические операции, без вызова функций и выполнения программного кода. Результаты успешных вычислений записываются в журнал вычислений. Сохранённые формулы находятся отдельно в `calculator_formulas.sqlite3`.

### Пользовательские сценарии калькулятора (Stage 9)
В панели «Вычисления» можно сохранять сценарии из нескольких шагов. Входные параметры задаются JSON-объектом, а шаги — JSON-массивом. В `variables` указывайте источник как `input.price` (входное значение), `step.subtotal` (результат предыдущего шага) либо числовую константу. ID шага должны быть уникальными; ссылка на шаг вперёд запрещена. Сценарий ограничен 20 входами и 20 шагами. Пример структуры есть в подсказке редактора интерфейса.


### Визуальный конструктор сценариев (Stage 10)
На вкладке «Калькуляторы» кнопка «+ Новый калькулятор» открывает конструктор. В нём добавляются параметры (подпись и имя в формулах) и шаги (название и формула). JSON вручную вводить не нужно. Имя параметра и имя результата шага подставляются автоматически по названию (первое слово, латиницей: «Цена за единицу» → `tsena`), их можно править. Откуда брать значение каждой переменной формулы, интерфейс определяет сам: если имя совпадает с параметром или результатом предыдущего шага, привязка ставится автоматически. Неоднозначные случаи выбираются из списка («параметр», «результат шага» или «Число…»), неразрешённые подсвечиваются, и сохранение не проходит, пока они не выбраны. При переименовании параметра или шага привязки в формулах следуют за новым именем. Формат хранения (`input.параметр`, `step.id`, число) не изменился, а ограничения безопасности и проверка сценария остаются на стороне Python-модуля `CalculatorScenarios`.


### Библиотека мини-калькуляторов (Stage 11)
На вкладке «Калькуляторы» блок «Добавить из шаблонов» содержит библиотеку готовых сценариев с категориями «Финансы», «Покупки», «Строительство» и «Повседневные». Выберите категорию и нажмите «Добавить», чтобы скопировать шаблон в свои калькуляторы. Собственные калькуляторы можно отнести к одной из категорий.

Кнопка «Экспорт JSON» сохраняет сценарии в переносимом формате MyAI; «Импорт JSON» загружает такой файл в другую установку. Импорт поддерживает до 100 сценариев за файл (до 64 КБ), проверяет все формулы и ссылки до записи и отклоняет набор целиком при ошибке или конфликте имён. Старые базы сценариев автоматически получают категорию «Пользовательские» без потери записей.


### Stage 12: редактирование и версии сценариев

В разделе «Мои сценарии» доступны действия «Изменить», «Копия» и «Версии». При сохранении изменений предыдущая конфигурация автоматически архивируется. Восстановление старой версии создаёт новую текущую версию, поэтому последующие изменения не уничтожают историю. Старые базы данных обновляются автоматически при запуске.


## Stage 13: локальный каталог обмена сценариями

На вкладке «Обмен» доступен локальный каталог публикаций. Калькулятор публикуется из меню «⋯» на его карточке; в каталоге его можно найти, установить и оценить от 1 до 5. Каталог и оценки хранятся отдельно в `calculator_sharing.sqlite3`.

Важно: это каталог внутри текущей установки MyAI, а не публичный интернет-магазин. Для обмена между разными компьютерами пока используйте существующий экспорт/импорт JSON. Перед установкой сценарии проходят ту же серверную валидацию и безопасную проверку формул, что и обычный импорт.

В списке каталога у каждой публикации есть кнопка «Снять с публикации»: запись и её оценки удаляются из каталога, а уже установленные копии остаются. Оценка — целое число от 1 до 5; оценок можно ставить несколько, средняя считается по всем.

## Stage 13.2: переработанная панель «Вычисления»

- **Три вкладки вместо одной ленты:** «Журнал» (по умолчанию), «Калькуляторы», «Обмен». Esc закрывает панель, стрелки влево и вправо переключают вкладки, фокус возвращается на кнопку, которой панель открывали.
- **Журнал:** статистика свёрнута в одну строку («Всего N · активных дней M · чаще всего: …»), график и разбивка раскрываются по кнопке «Подробнее». Поиск работает по мере ввода, даты применяются сразу, «Очистить журнал» убрано в меню «⋯».
- **Калькуляторы:** ваши мини-калькуляторы показаны карточками с полями ввода и кнопкой «Посчитать» прямо на карточке. «Изменить», «Копия», «Версии», «Опубликовать» и «Удалить» находятся в меню «⋯». Версии показываются на самой карточке с кнопкой «Восстановить».
- **Обмен:** публикации, установка, оценка кнопками 1–5 (без окна `prompt`), снятие с публикации, а также экспорт и импорт JSON.
- **Порядок параметров** калькулятора теперь сохраняется так, как его задал автор. Раньше сервер отдавал ключи JSON в алфавитном порядке, и после правки калькулятора порядок параметров навсегда менялся.
- Серверная часть, базы данных и форматы JSON не менялись.

## Stage 14: переработанная страница

- **Выезжающее меню.** Раньше на экранах уже 800 px боковая панель пропадала целиком, и вместе с ней «Новый чат», статус модели и кнопка повторной загрузки. Теперь на узких экранах она открывается кнопкой ☰ (закрывается Esc, кликом по затемнению или выбором пункта).
- **Боковая панель:** «Новый чат», «Вычисления», «Что умеет MyAI» и компактный статус системы. Подробности о модели, GPU и памяти раскрываются по кнопке «Подробнее». Кнопки «История» больше нет: она только заново подгружала уже открытый чат.
- **Меню «⋯» в верхней строке:** «Перезагрузить модель» и «Стереть историю и память…». Подтверждение показывается собственным диалогом с понятным текстом, и по умолчанию выбрана безопасная кнопка «Отмена».
- **Под каждым ответом:** «Копировать» и «Повторить вопрос» (последний отправляет тот же вопрос заново и добавляет его в разговор). У блоков кода есть своя кнопка «Копировать».
- **Ввод не блокируется:** пока MyAI отвечает, можно набирать следующее сообщение. Enter в это время не отправляет его, а подсказывает дождаться ответа или нажать «Стоп». Esc останавливает ответ.
- **Прокрутка:** пока вы читаете выше, новые части ответа не «утаскивают» чат вниз, а появляется кнопка ↓.
- **Пустой экран:** шесть карточек возможностей (погода, интернет, аниме, расчёты, память, компьютер) по два примера. Пример вставляется в поле ввода, но не отправляется сам. Тот же список открывается пунктом «Что умеет MyAI».
- **Ошибки** показываются прямо в сообщении, рядом с кнопкой «Повторить вопрос».
- **Доступность:** чат отмечен как `role="log"`, о готовности и остановке ответа сообщается скринридеру отдельно, диалоги удерживают фокус, у кнопок есть подписи.
- **Файлы:** CSS и JS вынесены из `index.html` в `static/`. В адрес файлов добавляется версия (`?v=`), поэтому после обновления браузер не берёт старый скрипт из кэша.

## Stage 15: окно «Память»

- В боковой панели появился пункт «Память» (🧠). Он открывает окно со всем, что MyAI помнит о вас между разговорами.
- **Заметки** показаны списком (новые сверху) с датой и кнопкой «Забыть». Удаляется ровно выбранная заметка. Команда «Забудь про …» в чате, наоборот, удаляет все похожие по словам, поэтому для точечного удаления теперь есть кнопка.
- **Имя** показывается отдельной строкой «Вас зовут …» с кнопкой «Забыть имя». Служебная заметка «Пользователя зовут …» дублирует имя, поэтому в списке скрыта. «Забыть имя» убирает и имя, и эту заметку, чтобы MyAI не продолжал обращаться по имени.
- **Новая заметка** добавляется полем наверху окна (то же, что «Запомни: …» в чате, до 500 символов). Дубли без учёта регистра не добавляются.
- Если заметку уже удалили из чата командой «Забудь …», устаревшая кнопка не ломает окно: список просто обновляется.
- Текст заметок всегда выводится как обычный текст, разметка в них не выполняется.
- Окно закрывается Esc, кнопкой ✕ или кликом по затемнению; фокус возвращается на пункт «Память».
- Новые маршруты: `GET /memory`, `POST /memory/add`, `POST /memory/forget` (по id), `POST /memory/forget_name`. Запросы на изменение, как и все остальные, требуют токена сессии.
